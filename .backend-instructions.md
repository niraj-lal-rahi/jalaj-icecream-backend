## Architecture Principles

### 1. **Separation of Concerns**
- Models: Handle database structure and relationships only
- Controllers: Handle HTTP requests/responses and routing
- Services: Encapsulate business logic (reusable across controllers/APIs)
- Traits: Share common response/functionality without code duplication
- Middleware: Handle cross-cutting concerns (auth, request timing, etc.)

### 2. **DRY (Don't Repeat Yourself)**
- **Rule**: If logic is used in 2+ places, extract to a Service class
- **Example**: Performance calculation logic → `SellerPerformanceService`
- **Single Source of Truth**: All related logic must originate from one place
- **Change Propagation**: One change in service = everywhere updates automatically

### 3. **SOLID Principles**
- **S**ingle Responsibility: One class = one reason to change
- **O**pen/Closed: Open for extension, closed for modification
- **L**iskov Substitution: Substitutable implementations
- **I**nterface Segregation: Specific interfaces, not fat ones
- **D**ependency Inversion: Depend on abstractions, not concretions

## Service Layer Pattern

### When to Create a Service
✅ **Create a Service when:**
- Logic is used in 2+ places (controllers, APIs, scheduled jobs)
- Business logic is complex (calculations, workflows, transformations)
- Logic needs to be reusable and testable in isolation
- Changes to logic should propagate everywhere automatically

❌ **Don't create a Service when:**
- It's a simple one-time operation
- It's a CRUD operation (use Model + FormRequest instead)
- It's just wrapping a single Eloquent query

### Service Class Template
```php
<?php

namespace App\Services;

use App\Models\User;
use Illuminate\Support\Collection;

class ExampleService
{
    /**
     * Public method - primary business logic
     * 
     * @param int $id
     * @return Collection
     */
    public function getProcessedData(int $id): Collection
    {
        $rawData = $this->fetchData($id);
        return $this->transformData($rawData);
    }

    /**
     * Private method - helper (not exposed publicly)
     */
    private function fetchData(int $id): Collection
    {
        return User::find($id)->getData();
    }

    /**
     * Private method - internal transformation
     */
    private function transformData(Collection $data): Collection
    {
        return $data->map(fn($item) => [
            'id' => $item->id,
            'processed' => $item->value * 2,
        ]);
    }
}
```

### Controller Usage
```php
<?php

namespace App\Http\Controllers\API;

use App\Services\ExampleService;

class ExampleController extends Controller
{
    public function index()
    {
        // ✅ CORRECT: Use service for reusable business logic
        $service = new ExampleService();
        $data = $service->getProcessedData(1);

        return $this->success($data, 'Data retrieved successfully');
    }
}
```

## API Standards

### Response Format (Unified via ApiResponse Trait)
```php
// ✅ Success Response
{
    "status": true,
    "message": "Operation successful",
    "data": { ... },
    "response_time_ms": 45.23
}

// ✅ Error Response
{
    "status": false,
    "message": "Operation failed",
    "error": "Detailed error message",
    "response_time_ms": 12.50
}
```

### HTTP Status Codes (Standard Convention)
```
200 → Success (GET, POST, PUT, PATCH)
201 → Created (POST)
204 → No Content (DELETE)
400 → Bad Request (validation failed)
401 → Unauthorized (not authenticated)
403 → Forbidden (not authorized)
404 → Not Found (resource doesn't exist)
422 → Unprocessable Entity (validation errors)
500 → Server Error
503 → Service Unavailable
```

### Controller Method Structure
```php
public function store(CreateSaleRequest $request)
{
    try {
        // Validation happens in FormRequest (CreateSaleRequest)
        $data = $request->validated();
        
        // Business logic via Service
        $service = new SaleService();
        $result = $service->createSale($data);
        
        // Unified response
        return $this->success(
            $result,
            'Sale created successfully',
            201  // Status code
        );
    } catch (CustomException $e) {
        return $this->error($e->getMessage(), 422, $e->getDetails());
    } catch (Exception $e) {
        Log::error('Sale creation failed', ['error' => $e->getMessage()]);
        return $this->error('Failed to create sale', 500, $e->getMessage());
    }
}
```

## Database Practices

### Model Guidelines
```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\HasMany;

class Seller extends Model
{
    // Only define database schema + relationships here
    // NOT business logic
    
    protected $fillable = ['name', 'number', 'email'];
    protected $hidden = ['created_at', 'updated_at'];
    protected $casts = [
        'created_at' => 'datetime',
        'updated_at' => 'datetime',
    ];

    // Relationships (not logic)
    public function sales(): HasMany
    {
        return $this->hasMany(Sale::class);
    }
}
```

### Query Optimization
```php
// ❌ N+1 Problem
$sellers = Seller::all();
foreach ($sellers as $seller) {
    $count = $seller->sales()->count();  // Query in loop!
}

// ✅ Eager load
$sellers = Seller::with('sales')->get();
foreach ($sellers as $seller) {
    $count = $seller->sales()->count();  // No query
}

// ✅ Even better: Use relation count
$sellers = Seller::withCount('sales')->get();
echo $seller->sales_count;  // No query
```

### Transactions for Consistency
```php
DB::transaction(function () {
    // Multiple operations within transaction
    $sale = Sale::create($data);
    $inventory->decrement('quantity', $sale->quantity);
    
    // If any fails, all rollback
    // If all succeed, all commit
});
```

## Error Handling & Logging

### Exception Handling Pattern
```php
try {
    // Business logic
    $result = $service->process($data);
    
} catch (ValidationException $e) {
    // Expected validation errors → 422
    Log::warning('Validation failed', ['errors' => $e->errors()]);
    return $this->error('Validation failed', 422, $e->errors());
    
} catch (NotFoundException $e) {
    // Resource not found → 404
    Log::notice('Resource not found', ['resource' => $e->resource]);
    return $this->error('Resource not found', 404, $e->getMessage());
    
} catch (UnauthorizedException $e) {
    // User not authorized → 403
    Log::warning('Unauthorized access', ['user' => auth()->id()]);
    return $this->error('Unauthorized', 403, $e->getMessage());
    
} catch (Exception $e) {
    // Unexpected errors → 500
    Log::error('Unexpected error', [
        'message' => $e->getMessage(),
        'file' => $e->getFile(),
        'line' => $e->getLine(),
        'trace' => $e->getTraceAsString(),
    ]);
    return $this->error('Server error', 500, $e->getMessage());
}
```

### Logging Standards
```php
// ✅ CORRECT structure
Log::info('Action completed successfully', [
    'user_id' => auth()->id(),
    'action' => 'sale_created',
    'sale_id' => $sale->id,
    'amount' => $sale->total,
    'response_time_ms' => 45.23,
]);

// ❌ INCORRECT
Log::info('Done');  // No context
Log::debug('sale_created');  // Use proper levels

// Log Levels (in order):
// EMERGENCY, ALERT, CRITICAL, ERROR, WARNING, NOTICE, INFO, DEBUG
```

## Performance Optimization

### 1. **Database Query Optimization**
```php
// ❌ Inefficient
$sellers = Seller::all();
$topSellers = array_slice($sellers->sortByDesc('revenue')->toArray(), 0, 3);

// ✅ Efficient
$topSellers = Seller::orderByDesc('revenue')->limit(3)->get();
```

### 2. **Caching Strategy**
```php
// Cache expensive calculations
$topPerformers = Cache::remember(
    'top_performers',
    now()->addHours(1),  // Cache for 1 hour
    function () {
        $service = new SellerPerformanceService();
        return $service->calculateAllSellerPerformance()->take(3);
    }
);

// Invalidate when data changes
Cache::forget('top_performers');
```

### 3. **Pagination for Large Results**
```php
// ❌ Load all (memory intensive)
$allSales = Sale::all();

// ✅ Paginate
$sales = Sale::paginate(50);
return $this->successPaginated($sales->items(), 'Sales retrieved', [
    'total' => $sales->total(),
    'per_page' => $sales->perPage(),
    'current_page' => $sales->currentPage(),
]);
```

### 4. **Collection over Query Loop**
```php
// ❌ Multiple queries
foreach ($sellerIds as $id) {
    $seller = Seller::find($id);  // Query per iteration
}

// ✅ Single query
$sellers = Seller::whereIn('id', $sellerIds)->get();
```

## Security Standards

### 1. **Authentication & Authorization**
```php
// Sanctum tokens (API)
$token = $user->createToken('mobile-token')->plainTextToken;

// Authorization checks
if (!auth()->check()) {
    return $this->error('Unauthorized', 401);
}

if (!auth()->user()->hasPermission('edit_sales')) {
    return $this->error('Forbidden', 403);
}
```

### 2. **Input Validation**
```php
// ✅ Always validate user input
public function store(CreateSaleRequest $request)
{
    // Validation happens in FormRequest (not controller)
    $data = $request->validated();
    // ... process validated data
}

// FormRequest class
class CreateSaleRequest extends FormRequest
{
    public function rules(): array
    {
        return [
            'seller_id' => 'required|exists:sellers,id',
            'item_id' => 'required|exists:items,id',
            'quantity' => 'required|integer|min:1',
            'price' => 'required|numeric|min:0',
        ];
    }
}
```

### 3. **SQL Injection Prevention**
```php
// ❌ NEVER use string interpolation
$sales = DB::select("SELECT * FROM sales WHERE seller_id = $id");

// ✅ Use parameterized queries
$sales = DB::select('SELECT * FROM sales WHERE seller_id = ?', [$id]);
// or
$sales = Sale::where('seller_id', $id)->get();
```

### 4. **Mass Assignment Protection**
```php
// Model class
protected $fillable = ['name', 'email', 'phone'];
// Only these can be mass-assigned; others ignored

// ❌ Bad
$seller = Seller::create($request->all());  // May expose is_admin, etc.

// ✅ Good
$seller = Seller::create($request->validated());  // Only validated fields
```

### 5. **CORS & API Security**
```php
// config/cors.php
'allowed_origins' => ['https://mobile-app.com', 'https://admin.domain.com'],
'allowed_methods' => ['GET', 'POST', 'PUT', 'DELETE'],
'allowed_headers' => ['Content-Type', 'Authorization'],
```

## Testing Standards

### Unit Test Structure
```php
<?php

namespace Tests\Unit\Services;

use Tests\TestCase;
use App\Services\SellerPerformanceService;
use App\Models\Seller;

class SellerPerformanceServiceTest extends TestCase
{
    public function test_calculate_all_seller_performance_returns_sorted_collection()
    {
        // Arrange: Set up test data
        Seller::factory()->count(5)->create();

        // Act: Execute the method
        $service = new SellerPerformanceService();
        $result = $service->calculateAllSellerPerformance();

        // Assert: Verify results
        $this->assertCount(5, $result);
        $this->assertTrue(
            $result[0]['performanceScore'] >= $result[1]['performanceScore']
        );
    }
}
```

### Feature Test Structure
```php
<?php

namespace Tests\Feature;

use Tests\TestCase;
use App\Models\User;

class SaleCreateTest extends TestCase
{
    public function test_authenticated_user_can_create_sale()
    {
        // Arrange
        $user = User::factory()->create();
        $this->actingAs($user, 'sanctum');

        // Act
        $response = $this->postJson('/api/sales', [
            'seller_id' => 1,
            'item_id' => 1,
            'quantity' => 10,
        ]);

        // Assert
        $response->assertStatus(201);
        $response->assertJsonPath('status', true);
    }
}
```

## Code Review Checklist

Before committing code, ensure:

- [ ] **DRY**: No duplicate logic (extract to Service if repeated)
- [ ] **SOLID**: Single responsibility, proper dependencies
- [ ] **Naming**: Clear, descriptive, follows conventions
- [ ] **Error Handling**: Try-catch with proper logging
- [ ] **Performance**: No N+1 queries, proper indexes
- [ ] **Security**: Input validated, SQL injection prevented
- [ ] **Testing**: Unit/feature tests for critical logic
- [ ] **Documentation**: Comments for complex logic
- [ ] **Logging**: Meaningful logs with context
- [ ] **Reusability**: Is this in a Service for other uses?

## Common Patterns

### Pattern 1: Service with Multiple Methods
```php
class SaleService {
    public function createSale(array $data) { ... }
    public function updateSale(int $id, array $data) { ... }
    private function validateSale(array $data) { ... }
    private function calculateTotals(array $data) { ... }
}
```

### Pattern 2: Trait for Code Reuse
```php
trait Timestampable {
    public function getFormattedCreatedDate() {
        return $this->created_at->format('Y-m-d H:i:s');
    }
}

// Use everywhere
class Sale extends Model {
    use Timestampable;
}
```

### Pattern 3: Repository Pattern (Advanced)
```php
// For complex queries, use repository
interface SellerRepositoryInterface {
    public function getTopPerformers(int $limit);
    public function findByNumber(string $number);
}

class SellerRepository implements SellerRepositoryInterface {
    public function getTopPerformers(int $limit) {
        return Seller::orderByDesc('performance_score')->limit($limit)->get();
    }
}
```
